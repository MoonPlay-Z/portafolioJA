Gestión y Control de Citas

Plataforma Web desarrollada para entidad pública MPPP

PHP PostgreSQL JavaScript Diseño Escalable

El Reto

La entidad pública necesitaba digitalizar y optimizar el proceso de agendamiento de citas para ciudadanos, reduciendo los tiempos de espera y mejorando la asignación de recursos.

Fui responsable del desarrollo y despliegue completo de la plataforma web, asegurando que fuera altamente disponible y fácil de usar para una base de usuarios muy diversa.

Solución Técnica

  • Arquitectura MVC: Se utilizó el patrón Modelo-Vista-Controlador para separar la lógica de negocio de la interfaz, facilitando la escalabilidad del proyecto.
  • Base de Datos Relacional: Diseño y optimización de esquemas en PostgreSQL para manejar un alto volumen de transacciones concurrentes.
  • Interfaz Interactiva: Uso de JavaScript vanilla para crear calendarios y validaciones en tiempo real en el frontend.
