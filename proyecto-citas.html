El Reto

Automatizar la gestión de órdenes y reservas en un comedor universitario, facilitando la compra de alimentos y la visualización de menús en tiempo real.

Fui responsable del desarrollo y despliegue completo de la plataforma web, asegurando que fuera altamente disponible y fácil de usar para una base de usuarios muy diversa.

Solución Técnica

Se diseñó una API RESTful con NestJS y Prisma, y una interfaz React/Next.js con autenticación JWT. Se usó Sharp para optimizar imágenes y Playwright para pruebas end‑to‑end. El proyecto se despliega en Netlify como funciones serverless y una base de datos PostgreSQL en Supabase.
